# Voxel Multiplayer Hills — v4.3.1 World Chat

This release makes chat actually work and brings it up to the standard of a modern chat app, while preserving the existing WebGL2 terrain, character, movement, and multiplayer systems.

## 4.3.1 — composer layout fix

`docs/styles.css` still carried the old chat rules, and its
`.chat-composer { display: grid; grid-template-columns: minmax(0,1fr) auto }`
gave the keyboard-help text its own grid column. That column took the width, the
composer was squeezed to a few pixels, and the message box rendered one
character wide with the placeholder running vertically down the panel — which
also made it effectively impossible to type.

All chat rules are now out of `styles.css` (it is game chrome only), the chat
stylesheet declares its own layout explicitly, and
`tests/css-isolation-test.mjs` fails the build if any `styles.css` selector ever
reaches into the chat UI again.

## What changed in 4.3.0

**Chat was completely dead in 4.2.1.** `docs/chat-parts/part02.b64` contained one extra character, so `atob()` threw, the whole module failed to load, and no chat feature ran at all. Parts are now generated by `tools/build-parts.py` with each part independently valid base64, and both loaders reject a corrupt part loudly instead of silently shifting every byte after it.

### Chat features

- Message grouping, date dividers, and a "new messages" divider
- Scroll anchoring with a **Jump to present** / `N new messages` button
- Replies with clickable parent previews
- Edit and delete your own messages, with tombstones and an `(edited)` badge
- Pinned messages with a dedicated panel
- Markdown: bold, italic, underline, strikethrough, inline code, code blocks, blockquotes, lists, spoilers, links, emoji shortcodes
- Searchable emoji picker for both the composer and reactions; 20 server-approved reactions with "who reacted" tooltips
- @mention autocomplete with arrow-key navigation, `@everyone` / `@here`, mention highlighting and badges
- Slash-command autocomplete; `/nick`, `/me`, `/w`, `/roll`, `/pins`, `/clear` added
- Auto-growing composer, draft persistence, `↑` to edit your last message
- Message search with match highlighting and result stepping
- Member list with online/offline sections, search, statuses, and per-member menus
- Right-click context menus on messages and members
- Desktop notifications, tab-title unread badge, mention-aware sounds and toasts
- Offline outbox: messages typed while disconnected queue and send on reconnect; rate-limited messages retry instead of failing
- Renaming yourself with `/nick` or the member panel, synced to the game HUD

### Backend

- Persistent chat history in `server/chat-state.json` — survives restarts
- Reply, edit, delete, pin, and rename support with ownership checks
- Server-side mention detection, private whispers, and a richer command set
- Message limit raised to 2000 characters; rate limit is now 5 messages per 5 seconds with a `retryAfter` hint

## Test locally

```bash
cd "/path/to/voxel-multiplayer-hills"
python3 local-dev.py
```

Open a second browser window to test multiplayer and chat.

## Editing chat or server code

Edit `docs/chat-source-v4.3.0.js` or `server/server-source.py`, then:

```bash
python3 tools/build-parts.py          # regenerate the base64 parts
python3 tools/build-parts.py --check  # verify parts match the sources
```

`--check` is worth running before every deploy — it is what would have caught the 4.2.1 corruption.

**Never rebuild the chat parts without checking them first.** The parts are what
production runs. If they have drifted ahead of `chat-source-v4.3.0.js` — which
they currently have, by about 1.4 KB — a plain rebuild deletes the difference.

```bash
python3 tools/reconcile-chat-parts.py --check   # report drift, change nothing
python3 tools/reconcile-chat-parts.py           # repair it (parts win)
```

`validate-persistent-world.py` warns when the two disagree, and fails on it with
`--strict` once you have reconciled them. See
[`ADMIN.md`](ADMIN.md#the-chat-module-is-untouched).

## Deploy

1. Upload this folder's **contents** to the repository root, preserving `docs/`, `server/`, and `tools/`.
2. GitHub Pages should publish either `/docs` or the repository root (the root `index.html` redirects to `/docs/`).
3. In Render, use **Manual Deploy → Deploy latest commit** because `autoDeployTrigger` is disabled.
4. Verify `https://voxel-multiplayer-hills-410-server.onrender.com/health` reports version `4.3.0` or later.

Render's free tier uses an ephemeral filesystem, so `chat-state.json` is lost when the instance restarts. Point `CHAT_STATE_PATH` at a persistent disk to keep history across restarts in production.

See [`CHAT.md`](CHAT.md) for the full command and shortcut reference, and
[`ADMIN.md`](ADMIN.md) for staff roles, moderation, and the admin control panel.
